# Sandev Shaman Companion

Android prototype for a manual companion to RAN Mobile.

## Current scope
- Start/pause a play session.
- Manual cooldown reminders for Heal, Buff, and Support.
- Clear status that the app is not connected to or controlling the game.
- No credentials, screen scraping, game input automation, or autonomous actions.

## Planned evaluation
1. Test the companion on the same Android phone as RAN Mobile.
2. Investigate documented/allowed integration options and the game rules.
3. If screen inspection is considered, require explicit user action and consent and keep it separate from automatic gameplay.
4. Consider limited, deterministic controls only if supported by the game and permitted by its server rules.

This is an early source prototype. It has not yet been built or tested on a physical device.
