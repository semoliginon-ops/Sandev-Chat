# SANDEV: STARFALL 1945

Independent Android prototype inspired by classic vertical-scrolling 1945 shooters. It has its own application ID and build workflow; it does not modify the Sandev Chat app module.

## Prototype scope
- Create a pilot and save the profile locally.
- Main menu: Campaign, Hangar, Workshop, Skills, Gemma profile/chat entry, Records, Settings.
- Playable vertical shooter with a companion ship that auto-fires.
- Local credits, XP, level progression (cap 1000), stage records and basic ship upgrades.
- Short battle comments; no manual chat box during battle.
- Separate GitHub Actions workflow builds a debug APK artifact.

## Honest status
This is a playable foundation, not the complete planned RPG. Companion actions/comments are deterministic prototype behavior, not yet decisions generated by the GGUF Gemma model. The menu chat screen explains that the Gemma runtime still needs to be integrated. No model file is bundled.

## Build
Run from this folder: `../native-sandev/gradlew --no-daemon assembleDebug`
